# Karate Math — Yonah's Multiplication Dojo

A web-based multiplication practice game for kids (tables up to 12×12), featuring karate avatars that punch and react based on your answers — plus a second round against the Ogre.

## Running the game

Just open `index.html` in a browser, or serve the folder:

```bash
python3 -m http.server 8000
```

then visit http://localhost:8000

## Files

- `index.html` — main page
- `app.js` — game logic
- `style.css` / `base.css` — styling
